# Hotel Cancellation Prediction App

Streamlit app for predicting the probability that a hotel booking will be cancelled.

## Live App

Deploy on Streamlit Community Cloud using:

- Repository: `tomaspfcrotty-spec/hotel-cancellation-prediction-app`
- Branch: `main`
- Main file: `app.py`

## Run Locally

```powershell
py -m streamlit run app.py
```

## Files

- `app.py`: Streamlit user interface
- `hotel_cancellation_pipeline.pkl`: trained machine-learning pipeline
- `requirements.txt`: Python dependencies for deployment

## Notes

This app is intended as a decision-support tool. Predictions should support, not replace, managerial judgement.
